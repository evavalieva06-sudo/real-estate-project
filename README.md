# real-estate-project
# Анализ рынка недвижимости Санкт-Петербурга

## О проекте

Анализ данных о предложении недвижимости в Санкт-Петербурге и Ленинградской области за период **2015–2018 годов**.

**Цель** — изучить структуру предложения, сезонность публикаций и снятий объявлений, а также выявить ключевые характеристики объектов (цена за квадратный метр, площадь, количество комнат).

🔗 **Интерактивный дашборд:** [Посмотреть в Yandex DataLens](https://datalens.yandex/rxcc9hxzqrfib)

---

## 📊 Дашборд

Для визуализации ключевых метрик был создан дашборд в Yandex DataLens, который позволяет в реальном времени отслеживать основные показатели рынка недвижимости.

### Основные возможности дашборда

- **Фильтрация** по:
  - типу недвижимости (апартаменты)
  - планировке (открытая)
  - дате объявления
  - населённому пункту
  - типу населённого пункта (город)
- **Ключевые метрики**:
  - Общее количество объектов: **20 008**
  - Средняя цена за квадратный метр
  - Средняя площадь
  - Среднее количество комнат
  - Среднее количество балконов

### Ключевые инсайты с дашборда

- Санкт-Петербург — абсолютный лидер рынка: на него приходится ~79% всех уникальных квартир (15 721 из 20 008) и самые высокие средние цены (~8 млн ₽).
- Рынок стал значительно активнее: количество объявлений выросло, а срок продажи сократился с ~1000+ дней до ~50–100 дней.
- Преобладает малогабаритное жильё: в среднем 2 комнаты, общая площадь ~62 м², жилая ~36 м², кухня ~11 м².
- Цены стабильны: средняя цена держится в диапазоне 5–8 млн ₽, без резких долгосрочных колебаний.
- Пригороды СПб (Всеволожск, Пушкин, Колпино, Гатчина) формируют основной объём предложения за пределами города, но с заметно более низкими ценами.

## Этапы работы

### 1. Подготовка данных (SQL)

- Данные очищены от выбросов по **площади, количеству комнат, балконам, высоте потолков** (отсечение по 1-му и 99-му перцентилям).
- Проведён анализ:
  - **Времени активности объявлений** (категории: до месяца, до трёх месяцев, до полугода, более полугода).
  - **Сезонности публикаций и снятий** по месяцам.
- Использованы: CTE, оконные функции, JOIN, агрегации, перцентили.

### 2. Визуализация (Yandex DataLens)

Создан интерактивный дашборд с фильтрами и ключевыми метриками.
